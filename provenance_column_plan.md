# Pre-registration: a provenance column on the 28 pre-registered elements

Brief AAC-8, 11 Nov 2026, adopted on its merits. Written and committed **before any element
was classified**. Nothing is classified in this file.

## 0. Why this and not a pixel comparison

"Pixel-by-pixel comparison against the source photograph" is not a coherent operation: a
drawing and a photograph differ everywhere, so the difference image is not a measurement of
anything. **The coherent version is a label per element**, and its value is that **only an
artist-added element can carry the author's message** — so a classification prunes the
candidate space at zero compute.

## 1. The element list, frozen here

The **28** elements of `r10_elements.json`, `E01`–`E28`, by their existing names and boxes.
**No element is added, split or removed.** §6's open `[SCOPE]` item notes the inventory has
no sub-elements; that gap stays open and is not addressed here, because adding sub-elements
mid-classification is how a list drifts toward whatever the current template needs.

## 2. The three labels, and nothing else

- **`in-source`** — the element is present in the underlying photograph or source image the
  composition is built on.
- **`artist-added`** — the element was put there by the composer of this image.
- **`undetermined`** — the evidence available here does not decide it.

A fourth label is not available. "Probably artist-added" is `undetermined`.

## 3. The evidence standard, fixed before looking

A label other than `undetermined` requires **at least one** of these, named per element:

1. **A measurement already in this report** that bears on it — ink depth, stroke width,
   rendering signature, resampling overshoot, letterform audit, the §6 contrast table.
2. **A rendering discontinuity** measured here: an element whose edge statistics differ from
   its surroundings in the way §6 records for the tablet's faint marks, which *"went through
   a step that the drawing they sit on did not."*
3. **Painted text or symbol content** that cannot be photographic — a letterform, a numeral,
   a slogan. A photograph can contain text; a *hand-lettered* glyph in this image's own hand
   cannot be photographic.

**Not acceptable as evidence:** that an element suits the template; that it looks painted;
that a word for it is BIP39. The first is the circularity this plan exists to prevent.

## 4. What an undetermined majority would mean, stated in advance

**If more than half of the 28 come back `undetermined`, the column is a null result and is
published as one** — it would mean this project cannot source the composition from what it
holds, which is a fact about our evidence and not about the artwork. It would specifically
**not** license treating the determined minority as the candidate set, because a
non-random subset of elements we happened to have measurements for is not the subset the
author added.

**And no element's label may change the grade of any word.** §2.17's grades stand on their
own evidence. A `in-source` label on an element whose word is `[MEASURED]` does not demote
that word, and an `artist-added` label does not promote one. The column is a prior over
where to look, never a verdict.

## 5. Word consequences

**No word enters any config from this, under any outcome.** A provenance label is a
statement about a region of an image, not about a phrase.

## 6. The standing instruction that is not relaxed

**No living artist is to be contacted, tagged, named publicly or identified**, and no
attempt is made to locate a source photograph by approaching a person. The standing
instruction is unchanged by this plan. Classification uses this project's own measurements
and the canonical file, and nothing else.
